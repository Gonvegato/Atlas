# ATLAS. — Cartografía Fantástica 2D y 3D (Godot 4)

Versión v0.1.1 — Corregido el cuelgue en arranque Android (OpenGL ES 3 + carga segura de scripts + 3D bajo demanda).

## Cómo actualizar el APK en GitHub
1. Sobrescribe los archivos de tu repositorio con el contenido de este ZIP y haz push a `main`.
2. Entra en **Actions → Compilar ATLAS. Android APK** y descarga el nuevo `ATLAS-android-apk`.
3. Desinstala la versión anterior en Android e instala el nuevo `.apk`.
